Tentang PPLG

Apa itu PPLG?

PPLG merupakan bidang yang mempelajari pengembangan perangkat, website, aplikasi, jaringan, dan gim.

Gambar kegiatan pengembangan perangkat lunak.

Urutan Membuat Website

  1. Membuat struktur HTML
  2. Membuat desain CSS
  3. Menambahkan JavaScript
  4. Melakukan Pengujian
HTML merupakan bahasa markup, bukan pemrograman. HTML berfungsi menyusun konten website.
Belajar pemrograman dimulai dari memahami struktur dan logika

Contoh kode: h1, p, dan section.
